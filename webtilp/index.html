The most complete TI calculator <=> computer transfer software.

TILP (formerly GtkTiLink) is the modern linking suite for TI calculators. Send files, capture screens, upgrade OS images, manage backups, and keep devices in sync across z80/eZ80, 68k, and Nspire models.

tilibs

tilibs are the libraries powering TILP:

  • libticonv: Charset conversion and model utilities to keep TI filenames and text correct across platforms.
  • libtifiles: TI file format toolkit for variables, apps, OS files, backups, and TiGroup archives.
  • libticables: Link cable layer handling physical and virtual connections, including USB, parallel, serial, and emulator-backed links.
  • libticalcs: High-level calculator protocol layer for transfers, screenshots, remote control, and device discovery.
