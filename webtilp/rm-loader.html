RM native loader — OS transfer

Hold OPTN + EXP while powering on to open Flash Memory. Use the Casio USB-to-2.5 mm serial cable, and close FA-124 first.

Transfers the PROGRAM/OS only. The native LOADER is not included. The serial cable is not used to identify the installed PROGRAM or calculator model.

First select Casio RM-7000 or RM-9000 (native OS loader) in WebTILP Settings, then click Connect Calculator.

WebSerial requires desktop Chrome or Edge over HTTPS or localhost, or the Web'nTILP desktop app.

19200 baud · 8O2

Send OS to calculator

On the calculator, choose Download [1], then confirm with [EXE]. Select an 896 KiB RM installation .bin. WebTILP checks the file before transmitting only the declared PROGRAM.

No installation file selected.

Receive OS from calculator

Start reception here first, then choose Upload [2] on the calculator and confirm with [EXE]. The received PROGRAM and its header are rebuilt into an installable .bin.

No complete OS received yet.

Transfer status

Connect the serial cable to begin.

After a transfer or an error the port closes. Before retrying, return to the Flash Memory menu and reconnect. Cancelling a send may leave an incomplete PROGRAM; reinstall a known-good .bin using Download [1], then [EXE].
